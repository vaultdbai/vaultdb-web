VaultDB Valuation

VaultDB Valuation is a domain package for pricing models, fair-value computation, and mark-to-market. It extends the VaultDB Core platform with valuation-specific functionality.

Features

Valuation Capabilities

  • Pricing Models: Pluggable pricing engines for derivatives and securities.
  • Fair-Value Computation: Compute fair values under multiple methodologies.
  • Mark-to-Market: Daily mark-to-market and valuation adjustments.

Installation

Prerequisites

  • Python 3.12 or higher
  • vaultdb.core >= 3.18.0

Install from PyPI

pip install vaultdb.valuation

Install from Source

# Clone the repository
git clone https://github.com/vaultdbai/valuation.git
cd valuation

# Install in development mode
pip install -e .

# Install development dependencies
pip install -e ".[dev]"

Quick Start

import vaultdb_valuation

Development

VaultDB Valuation uses Ruff for linting and formatting (160 char limit) and Mypy for strict typing.

Commands

# Format and Lint
ruff format .
ruff check . --fix

# Type checking
mypy src/

# Testing
python -m pytest -v
