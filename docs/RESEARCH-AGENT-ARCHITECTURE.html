Research Agent Architecture — Extensible Design

Vision

The vaultdb.crawler.research framework provides a pluggable research agent system where anyone can build domain-specific research agents by extending a base class. The insurance prospectus hunter is the first concrete implementation, but the framework is designed for:

  • Regulatory data research (NAIC, SERFF, state DOI portals)
  • Scenario data research (Fed economic data, treasury curves, equity indices)
  • Assumption data research (SOA mortality tables, lapse studies, expense benchmarks)
  • Competitive intelligence (product comparisons, rate sheet tracking)
  • Academic/quantitative research (papers, models, calibration data)

Core Abstractions

1. BaseResearchAgent

The abstract base that all research agents extend:

class BaseResearchAgent(ABC):
    """Base class for all research agents.

    Subclasses define:
    - What to search for (target documents, data types)
    - Where to search (data sources to use)
    - How to validate (LLM prompts, acceptance criteria)
    - Where to store results (directory structure)
    """

    # -- Override in subclass --
    name: str                          # e.g. "insurance", "scenario"
    description: str                   # Human-readable description

    @abstractmethod
    def get_sources(self) -> list[DataSource]:
        """Return the data sources this agent searches."""

    @abstractmethod
    def get_advisor(self) -> BaseLLMAdvisor | None:
        """Return the domain-specific LLM advisor."""

    @abstractmethod
    def get_storage(self) -> StorageBackend:
        """Return the storage backend for results."""

    @abstractmethod
    def validate_document(self, content: bytes, metadata: dict) -> bool:
        """Validate whether a downloaded document is relevant."""

    # -- Provided by base --
    def hunt(self, target: str, **kwargs) -> dict:
        """Full autonomous hunt for a target (company, topic, etc.)."""

    def search(self, query: str, **kwargs) -> list[dict]:
        """Search across configured sources."""

    def download(self, url: str, **kwargs) -> dict | None:
        """Download and validate a single document."""

    def list_downloads(self, target: str = "") -> dict:
        """List downloaded documents."""

    def status(self) -> dict:
        """Agent status including LLM availability."""

    def get_tool_definitions(self) -> list[dict]:
        """Return Anthropic SDK tool definitions for chatbot integration."""

    def dispatch_tool(self, tool_name: str, tool_input: dict) -> Any:
        """Dispatch a tool call from the chatbot."""

2. DataSource Protocol

Pluggable sources that agents compose:

class DataSource(Protocol):
    """Protocol for pluggable research data sources."""

    name: str                          # e.g. "sec_edgar", "serff"
    description: str

    def search(self, query: str, **kwargs) -> list[SearchResult]:
        """Search this source and return results."""

    def download(self, result: SearchResult) -> DownloadResult | None:
        """Download a specific result."""

    @property
    def available(self) -> bool:
        """Whether this source is currently accessible."""

Built-in sources: - WebSearchSource — Google/DuckDuckGo web search - WebCrawlSource — LLM-guided deep crawling - SECEdgarSource — SEC EDGAR API - SERFFSource — SERFF Filing Access (Playwright) - NAICSource — NAIC company database - StateDOISource — State DOI portals

3. StorageBackend Protocol

Where results are saved:

class StorageBackend(Protocol):
    """Protocol for research result storage."""

    def save(self, content: bytes, metadata: dict) -> str:
        """Save content, return path."""

    def exists(self, content: bytes) -> bool:
        """Check for duplicates."""

    def list(self, target: str = "") -> list[dict]:
        """List saved items."""

    def remove(self, path: str) -> bool:
        """Remove an item."""

Built-in: - FileStorageBackend — Local filesystem (default, uses PROSPECTUS_DIR) - Future: DuckLake storage, S3, etc.

4. AgentRegistry

Discovery and registration:

class AgentRegistry:
    """Registry for research agents — enables plugin discovery."""

    _agents: dict[str, type[BaseResearchAgent]]

    def register(self, agent_cls: type[BaseResearchAgent]) -> None:
        """Register an agent class."""

    def get(self, name: str) -> type[BaseResearchAgent]:
        """Get agent class by name."""

    def list(self) -> list[str]:
        """List registered agent names."""

    def discover(self) -> None:
        """Auto-discover agents via entry_points."""

# Global registry
registry = AgentRegistry()

Concrete Agents

InsuranceResearchAgent

  • Sources: WebSearch, WebCrawl, SECEdgar, SERFF, NAIC, StateDOI
  • Advisor: InsuranceAdvisor (FIA/RILA/VA/FA prompts)
  • Storage: FileStorage under prospectuses/{Company}/
  • Targets: Company names → autonomous multi-phase hunt

RegulatoryResearchAgent

  • Sources: SERFF, NAIC, StateDOI
  • Advisor: InsuranceAdvisor (regulatory prompts)
  • Storage: FileStorage under prospectuses/{Company}/SERFF_Filings/
  • Targets: Company + state → filing search

ScenarioResearchAgent (future)

  • Sources: FRED, Treasury.gov, WebSearch
  • Advisor: ScenarioAdvisor (rate/curve prompts)
  • Storage: FileStorage under data/scenarios/
  • Targets: Curve types, date ranges → rate data download

AssumptionResearchAgent (future)

  • Sources: SOA website, WebSearch, academic papers
  • Advisor: AssumptionAdvisor (mortality/lapse prompts)
  • Storage: FileStorage under data/assumptions/
  • Targets: Table types → SOA data download

Integration Points

1. CLI (vaultdb-research)

vaultdb-research hunt insurance --company "Athene" --include-sec --include-regulatory
vaultdb-research hunt regulatory --company "Jackson" --states TX,NY
vaultdb-research search insurance --query "FIA prospectus 2025"
vaultdb-research list insurance --company "Athene"
vaultdb-research status
vaultdb-research agents                    # list available agents

2. Dashboard Chatbot Tools

Each agent auto-generates tool definitions via get_tool_definitions(): - research_hunt — autonomous hunt - research_search — search across sources - research_download — download specific URL - research_list — list downloads - research_status — agent status

3. Claude Code Skill (/research)

Slash command that loads the research agent and provides instructions.

4. Plugin Entry Point

# kronos-skill.toml
[skill]
name = "research"
entry_point = "vaultdb.crawler.research.plugin:get_tool_definitions"

5. Python API

from vaultdb.crawler.research import ResearchAgent

agent = ResearchAgent("insurance")
result = agent.hunt("Athene", include_sec=True)

Extension Example — Building a Custom Research Agent

from vaultdb.crawler.research.base import BaseResearchAgent, DataSource
from vaultdb.crawler.research.sources import WebSearchSource
from vaultdb.crawler.research.registry import registry

class CreditRatingResearchAgent(BaseResearchAgent):
    name = "credit_ratings"
    description = "Research credit ratings and rating actions for insurers"

    def get_sources(self):
        return [
            WebSearchSource(),
            MoodysSource(),     # custom source
            SPGlobalSource(),   # custom source
        ]

    def get_advisor(self):
        return CreditRatingAdvisor()  # custom prompts

    def get_storage(self):
        return FileStorageBackend(base_dir=Path("data/ratings"))

    def validate_document(self, content, metadata):
        # Custom validation logic
        ...

# Register so it appears in CLI and dashboard
registry.register(CreditRatingResearchAgent)

Implementation Plan

  2. Create sources.py with DataSource protocol and built-in sources
  3. Create storage.py with StorageBackend protocol
  4. Create registry.py with AgentRegistry
  5. Move insurance-browser code into agents/insurance.py
  6. Move regulatory code into agents/regulatory.py and sources/

Phase 2: Integration

  1. Create cli.py with argparse CLI
  2. Create plugin.py with dashboard tool definitions
  3. Add Claude Code skill
  4. Add installer registration
  5. Add tests

Phase 3: Additional Agents (future PRs)

  1. ScenarioResearchAgent
  2. AssumptionResearchAgent
  3. Competitive intelligence agent

File Naming Conventions

  • base.py — abstract base classes and protocols
  • agents/*.py — concrete agent implementations
  • sources/*.py — data source implementations
  • registry.py — agent discovery and registration
  • storage.py — storage backends
  • advisor.py — domain-specific LLM advisors (kept at research/ level for backward compat)
  • config.py — shared configuration constants
  • cli.py — CLI entry point
  • plugin.py — chatbot plugin entry point
