Asset Overview — Pricing Engines & Valuation

Architecture

vaultdb.asset is the pricing and valuation domain package in the VaultDB ecosystem. It consumes instruments and market data from vaultdb.market, applies QuantLib and PyTorch-based pricing engines, and persists results as TimeSeriesModel records.

Dual Pricing Paths

Every engine implements two pricing paths:

  • price_single() — QuantLib for single-instrument correctness and reference validation
  • price_bulk() — PyTorch tensors for vectorized batch pricing with GPU support

The price() dispatcher automatically selects the optimal path based on input count.

torch.autograd for Greeks

Instead of bump-and-reprice (2N+1 valuations for N Greeks), all engines use torch.autograd for exact first-order derivatives in a single backward pass. Second-order Greeks (gamma, convexity) use a second backward pass. This covers: duration, modified duration, convexity, DV01, delta, gamma, vega, theta, rho, CS01.

Padded Tensor Matrices

cashflows.py generates (N, max_cashflows) tensors with boolean masks, enabling batched matrix operations across instruments with different payment schedules. All cashflow schedules are padded to the same maximum length.

Key Components

Device Manager (device.py)

Singleton that manages the PyTorch device (CPU or CUDA). All tensor operations route through get_device(). Override with set_device("cuda") or set_device("cpu").

Market Environment (market_environment.py)

Bundles all market data for a single valuation run. Acts as the bridge between vaultdb_market QuantLib objects and the PyTorch tensor world.

Key methods:

Method Returns Description
get_curve(name) ql.YieldTermStructureHandle Cached QL curve handle
get_vol_surface(name) ql.BlackVolTermStructureHandle Cached QL vol surface handle
get_discount_factors(curve, year_fractions) torch.Tensor QL discount factors as tensor
get_zero_rates(curve, year_fractions) torch.Tensor QL zero rates as tensor
get_forward_rates(curve, t1, t2) torch.Tensor QL forward rates as tensor
get_implied_vol(surface, strikes, year_fractions) torch.Tensor QL implied vols as tensor

Valuation Result (results.py)

ValuationResult(TimeSeriesModel) — persists pricing outputs per instrument per valuation date.

Primary keys: (valuation_date, symbol, engine)

Columns: npv, clean_price, dirty_price, accrued_interest, duration, modified_duration, convexity, dv01, delta, gamma, vega, theta, rho, cs01

Cashflows (cashflows.py)

Shared logic for generating cashflow schedules as padded tensors. Used by bond, swap, cap/floor, and CDS engines.

Key functions:

Function Description
generate_schedule(...) QuantLib schedule of coupon dates
build_fixed_bond_tensors(...) (N, max_cf) padded cashflow + year fraction + mask tensors
build_swap_leg_tensors(...) (N, max_periods) padded notional + year fraction + accrual tensors

Pricing Engines

Base Classes (engines/base.py)

  • PricingEngine — Abstract base with price_single(), price_bulk(), and price() dispatcher
  • TorchMixin — Shared tensor utilities: _to_tensor(), _scalar_tensor(), _compute_greeks_via_autograd(), _normal_cdf(), _normal_pdf()

Bond Engine (engines/bond.py)

Feature QuantLib Path PyTorch Path
Fixed-Rate FixedRateBond + DiscountingBondEngine Cashflow matrix × discount factor tensor
Zero-Coupon ZeroCouponBond + DiscountingBondEngine face × df(maturity)
Floating Via QL index Forward rate tensor × accrual × df
Greeks BondFunctions.duration() / convexity() torch.autograd on rate shift

Bulk math (fixed bonds):

cf_amounts:  (N, max_cf)   — coupon + principal at maturity
yf:          (N, max_cf)   — year fractions to payment
df_shifted:  (N, max_cf)   — discount_factor × exp(-shift × yf)
NPV = sum(cf_amounts × df_shifted × mask, dim=1)
duration = -(1/NPV) × dNPV/d(shift)    # via autograd
convexity = (1/NPV) × d²NPV/d(shift)²  # second backward pass

Swap Engine (engines/swap.py)

Leg Computation
Fixed notional × fixed_rate × accrual × df summed per period
Floating notional × forward_rate × accrual × df summed per period
NPV floating_leg - fixed_leg (payer convention)
DV01 torch.autograd on rate shift

Option Engine (engines/option.py)

Vectorized Black-Scholes for European options:

d1 = (log(S/K) + (r + 0.5σ²)T) / (σ√T)
d2 = d1 - σ√T
call = S·N(d1) - K·e^(-rT)·N(d2)
put  = K·e^(-rT)·N(-d2) - S·N(-d1)

All Greeks (delta, gamma, vega, theta, rho) via torch.autograd on S, sigma, r, T. American options fall back to QuantLib binomial in price_single().

Cap/Floor Engine (engines/capfloor.py)

Each caplet/floorlet priced as a Black76 call/put on the forward rate:

caplet = df × accrual × notional × Black76(F, K, σ, T_option)

Vectorized across all caplets of all instruments simultaneously.

Swaption Engine (engines/swaption.py)

Black76 on the forward swap rate:

NPV = notional × annuity_factor × Black76(forward_swap_rate, K, σ, T_exercise)

FX Forward Engine (engines/fx_forward.py)

Covered interest-rate parity:

NPV = notional × (implied_forward - contract_rate) × df_domestic

CDS Engine (engines/cds.py)

Flat hazard rate model:

h = spread / (1 - recovery)
survival(t) = exp(-h × t)
premium_leg = Σ(spread × notional × accrual × df × survival)
protection_leg = Σ(notional × (1-R) × default_prob × df)
NPV_buyer = protection_leg - premium_leg
CS01 via autograd on spread input

FRA Engine (engines/fra.py)

NPV = notional × (forward_rate - contract_rate) × accrual × df(end)

Task Orchestration (tasks.py)

price_portfolio(symbols, curve_name, vol_surface_name, persist)

  1. Loads instruments by symbol from vaultdb_market
  2. Groups by instrument type (Bond, Swap, Option, etc.)
  3. Creates a single MarketEnvironment (curves built once, shared)
  4. For each group, instantiates the matching engine and calls price()
  5. Concatenates results and optionally bulk_load() into ValuationResult

price_instrument(symbol, instrument_type, curve_name, vol_surface_name)

Prices a single instrument. Useful for interactive/REPL usage.

Usage Examples

Basic Portfolio Pricing

from datetime import date
from vaultdb import settings
from vaultdb_asset import price_portfolio

settings.valuation_date = date(2026, 3, 27)
results = price_portfolio(
    symbols=["BOND_001", "SWAP_002", "OPT_003"],
    curve_name="USD_SOFR",
)
print(results[["symbol", "npv", "duration", "delta"]])

Single Instrument Pricing

from vaultdb_asset import price_instrument

result = price_instrument("BOND_001", "Bond", curve_name="USD_SOFR")
print(result)  # {"npv": 98.5, "duration": 4.2, "dv01": 0.042, ...}

Direct Engine Usage (Bulk)

from vaultdb_asset import BondPricingEngine, MarketEnvironment
from vaultdb_market.instruments import Bond

bonds = Bond.search(bond_type="FIXED")
market = MarketEnvironment()
engine = BondPricingEngine(curve_name="USD_SOFR")
df = engine.price_bulk(bonds, market)

GPU Acceleration

from vaultdb_asset import set_device
set_device("cuda")  # All subsequent tensor ops use GPU
results = price_portfolio(symbols=large_portfolio, curve_name="USD_SOFR")
