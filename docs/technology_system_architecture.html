Request Flow: Chat Message to Workflow Execution

This is the complete path from a user typing a message to workflow results:

sequenceDiagram
    participant USER as Actuary (Browser)
    participant DASH as Dashboard (8050)
    participant HUB as ChatHub (8060)
    participant UP as UserProcess (9100)
    participant CLAUDE as Claude API
    participant CORE as VaultDB Core
    participant WORKER as Celery Worker

    rect rgb(30, 30, 60)
        Note over USER,CLAUDE: Phase 1: AI Conversation
        USER->>DASH: "Run Q1 valuation for TED-FA-2026"
        DASH->>HUB: POST /chatbot/{user}/message
        HUB->>HUB: Spawn UserProcess if needed
        HUB->>UP: Forward (X-Hub-Token)
        UP->>CLAUDE: messages.create(tools=TOOL_DEFINITIONS)
        CLAUDE-->>UP: tool_use: list_modules
        UP->>UP: dispatch_tool("list_modules")
        UP->>CLAUDE: tool_result: {modules: ...}
        CLAUDE-->>UP: tool_use: propose_workflow
        UP->>HUB: POST /_hub/api/workflows/submit
        HUB->>CORE: submit_workflow(definition)
        CORE-->>HUB: WorkflowRun (PENDING_APPROVAL)
        HUB-->>UP: {workflow_id, status}
        UP->>CLAUDE: tool_result: {workflow_id}
        CLAUDE-->>UP: end_turn: "I've proposed a workflow..."
        UP-->>HUB: MessageResponse
        HUB-->>DASH: JSON response
        DASH-->>USER: Show DAG + Approve button
    end

    rect rgb(30, 60, 30)
        Note over USER,CORE: Phase 2: Human Approval
        USER->>DASH: Open /workflow?id=abc
        DASH->>DASH: Record viewer_opened_at
        USER->>USER: Review DAG, steps, assumptions
        USER->>DASH: Click "Approve" + review notes
        DASH->>HUB: POST /approvals
        HUB->>CORE: PolicyEnforcer.enforce(context)
        CORE-->>HUB: passed=True
        HUB->>CORE: create_approval() → HMAC token
        CORE-->>HUB: ApprovalRecord
        HUB-->>DASH: 200 OK
        DASH-->>USER: "Approved" badge
    end

    rect rgb(60, 30, 30)
        Note over USER,WORKER: Phase 3: Execution
        USER->>DASH: Click "Execute"
        DASH->>HUB: POST /workflows/{id}/execute
        HUB->>CORE: execute_workflow(id)
        CORE->>CORE: Triple-gate: exists? valid? HMAC OK?
        CORE->>CORE: Topological sort steps
        loop Each step in DAG order
            CORE->>WORKER: _call_task(step.task, kwargs)
            WORKER->>WORKER: Execute domain computation
            WORKER-->>CORE: Step result
            CORE->>CORE: Resolve $step_xxx refs for next step
        end
        CORE-->>HUB: WorkflowRun (DONE)
        HUB-->>DASH: Updated workflow
        DASH-->>USER: Show results
    end

    A["Human clicks Approve"] --> B["PolicyEnforcer

    B -->|passed| C["HMAC-SHA256
generate token"]
    C --> D["Persist
ApprovalRecord"]
    D --> E["Human clicks Execute"]
    E --> F["Triple Gate
1. Exists?
2. Valid?
3. HMAC OK?"]
    F -->|all pass| G["Execute DAG"]
    F -->|any fail| H["DENIED"]
