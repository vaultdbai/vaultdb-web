Frequently Asked Questions
What is VaultDB?

VaultDB is the in-process database that allows any process to utilize local compute capability for query and data processing instead of relying on a centralized database server which becomes a bottleneck in distributed computing environments. VaultDB and VaultDB HUB data lakes are perfect for distributed cloud processes and on IoT devices.

Each process uses VaultDB library (python, nodejs, odjbc, jdbc) for data access and processing and once ready pushes data to centralized VaultDB HUB.

VaultDB also has built-in GRC capability that allows users to secure data and access. In short VaultDB frees models, business applications and Internet of Things (IoT) through in-process database with centralized VaultDB Hub data lake.

VaultDB is a perfect tool for ETL using tools such as AWS Glue as it supports different input formats such as CSV, Parquet, JSON etc. Vectorization is used to support faster data processing for ETL type of work.

VaultDB is free to use. We do not charge anything. You pay for storage and compute you use to your cloud provider.

Why should I consider using VaultDB for my IoT devices?

IoT devices generate vast amounts of data real-time which is invaluable for organizations and individuals. This data may be a perfect source to train AI/AGI models.

VaultDB is perfect for this type of use case as it provides local writes when a device is disconnected and has push ability to send data to centralized VaultDB Data Lake.

Your IoT devices can also use VaultDB to query merged local and centralized data at speed.

VaultDB is highly cost effective as you only have to bear storage cost as there is no server running all the time.

Why should I consider using VaultDB for Model training and testing?

Machine Learning Model training and testing requires significant data preparation, data engineering and security.

VaultDB is built on DuckDB which is designed for big data analytics and data engineering. VaultDB's Python package is integrated with pandas, numpy and makes data processing multiple folds faster as it uses Vectorization. VaultDB also supports PyArrow and many more extensions supported by DuckDB.

VaultDB Governance, Risk and Control capabilities such as Fortress, Column level security, and Roles help prevent model bias and unnecessary PI or PII information during training.

VaultDB also allows you to partition tables for faster processing of data, which is paramount in a world where GPU and CPU compute costs are astronomical.

What is Data Inheritance?

Your local VaultDB instance works like a database server that returns merged results from remote and local datasets. This way you can develop like you are working in production. Just enable data inheritance to true and see the magic — you can even hide remote rows you are inheriting from for your local testing.
