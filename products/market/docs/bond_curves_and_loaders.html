Bond Market Curves & Data Loaders

Module: vaultdb_market
Path: market/src/vaultdb_market/tasks/
Updated: 2026-04-01

Overview

The bond market data subsystem provides:

  1. Data Loaders — fetch rates and spreads from free public APIs and FRED into SimpleQuote records
  2. Curve Definitions — ORM-backed YieldCurve and OASSpreadCurve records bootstrapped from those quotes
  3. Daily Save Orchestrator — a single scheduled entry-point that runs all loaders and refreshes all spread curves
  4. Programmatic Builder — YieldCurveBuilder for in-memory curve construction without database round-trips

Curve Architecture

Each bond market segment uses a two-layer curve model:

Base Yield Curve  (YieldCurve ORM record)
    └── bootstrapped from quoted deposits + swaps
    └── produces ql.YieldTermStructureHandle

OAS Spread Curve  (OASSpreadCurve ORM record)
    └── wraps base curve + flat spread (decimal)
    └── uses ql.ZeroSpreadedTermStructure
    └── spread updated daily from ICE BofA OAS index quotes

Curve Definitions

Name Currency Short End Long End Floating Index

Spreads are updated daily from the latest SimpleQuote observations after each data load.

Daily Save Orchestrator

daily_save.run() — the primary Celery/cron entry-point for end-of-day market data ingestion.

from vaultdb_market.tasks.daily_save import run_today

# Run all loaders for today
results = run_today(fred_api_key="YOUR_KEY")
# Returns: {"valuation_date": "2026-04-01", "ust_spot_2026": 13, ..., "total_rows": 847}

Execution order

1. load_corp_bonds   → UST_SPOT rates + CORP OAS indices
2. load_sofr         → SOFR overnight + SOFR averages
3. load_mbs          → SOFR + MBS OAS
4. load_eur_bonds    → ECB govt curve + Euribor + EUR swaps
5. load_em_bonds     → Treasury base + World Bank + EM OAS
6. _update_all_oas_curves → refresh all OASSpreadCurve.spread from latest quotes

Celery beat schedule (example)

app.conf.beat_schedule["daily-market-save"] = {
    "task": "vaultdb_market.celery.daily_market_save",
    "schedule": crontab(minute=30, hour=18, day_of_week="1-5"),  # 6:30 PM ET, Mon–Fri
}

Programmatic Curve Builder

For in-memory curve construction (no DB, no quotes needed):

from vaultdb_market.curve_builder import YieldCurveBuilder, bootstrap_from_rates

# Fluent API
handle = (
    YieldCurveBuilder()
    .add_deposit(1,  0.0530)   # 1M deposit
    .add_deposit(3,  0.0525)   # 3M deposit
    .add_deposit(6,  0.0512)   # 6M deposit
    .add_future(1,   94.72)    # 1st IMM futures price
    .add_future(2,   94.95)    # 2nd IMM futures price
    .add_swap(24,    0.0485)   # 2Y swap
    .add_swap(60,    0.0462)   # 5Y swap
    .add_swap(120,   0.0448)   # 10Y swap
    .add_swap(360,   0.0435)   # 30Y swap
    .build(interpolation="LOG_LINEAR")
)

# Simple dict API
handle = bootstrap_from_rates(
    deposits={1: 0.053, 3: 0.052, 6: 0.051},
    futures={1: 94.72, 2: 94.95},
    swaps={24: 0.048, 60: 0.046, 120: 0.044, 240: 0.043, 360: 0.042},
)

# Inject into MarketEnvironment (bypasses DB lookup)
market.load_curve_from_builder("MY_CUSTOM_CURVE", handle)

MarketEnvironment Curve API

from vaultdb_asset.market_environment import MarketEnvironment

market = MarketEnvironment()

# Load all bond curves from DB in one shot (warms cache)
status = market.load_all_bond_curves()

# Get curve by bond segment
handle = market.get_curve_for_segment("CORP_IG")    # UST_SPOT + IG OAS
handle = market.get_curve_for_segment("MBS_AGENCY") # SOFR_SWAP + MBS OAS
handle = market.get_curve_for_segment("EM_HY")      # UST_SPOT + EM HY OAS
handle = market.get_curve_for_segment("EUR_IG")     # EUR_EURIBOR + IG OAS

# Load a specific OASSpreadCurve from DB
handle = market.load_oas_curve_from_db("CORP_HY")

# Get spread-adjusted discount factors as torch tensor
import torch
yf = torch.tensor([1.0, 2.0, 5.0, 10.0], dtype=torch.float64)
dfs = market.get_spread_adjusted_discount_factors("UST_SPOT", 0.015, yf)
# → tensor of DFs with 150bps spread applied

FRED Series Registry (data_sources.py)

from vaultdb_market.data_sources import (
    FRED_CORP_OAS,    # ICE BofA US Corp OAS (AAA, AA, A, BBB, IG, BB, B, CCC, HY)
    FRED_MBS_OAS,     # ICE BofA Agency MBS OAS
    FRED_EURIBOR,     # Euribor 1M / 3M / 6M / 12M
    FRED_EUR_SWAPS,   # ICE EUR OIS swaps 1Y–30Y
    FRED_EM_SPREADS,  # ICE BofA EM OAS (total, IG, HY)
)

Get a free FRED API key at: https://fred.stlouisfed.org/docs/api/
