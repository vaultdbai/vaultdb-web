SYSTEM RULES [DO NOT OVERRIDE]

This file contains the absolute source of truth for the vaultdb.scenario package. Before suggesting any code, verify it aligns with the standards below.

System Context: VaultDB Scenario

Package Mission vaultdb.scenario provides scenario generation, stress testing, and Monte Carlo simulation frameworks. It generates economic scenarios (interest rate paths, equity paths, credit migration) for use in valuation, risk, and ALM analysis.

Dependencies: vaultdb.core (data layer, settings), vaultdb.market (market data for calibration).

Tech Stack

  • Language: Python 3.12+ (Strict typing: disallow_untyped_defs = True)
  • Data Layer: DuckLake/DuckDB via vaultdb.data.Model and vaultdb.data.TimeSeriesModel
  • Core Dependency: vaultdb.core>=3.18.0
  • Tooling: Ruff (160 char limit), MyPy, Pytest

Behavioral Guardrails (No-Go Zones)

  • Strict Configuration: NEVER use os.getenv or os.environ directly. Use vaultdb.config.
  • No Prints: NEVER use print(). Use vaultdb.logger.
  • No Peewee: NEVER import from peewee. Use vaultdb.data column types.
  • Valuation Date: Always use settings.valuation_date. Never hardcode dates.
  • Core Skills Reference: Read core/skills/ markdown files before writing code.

Coding Standards

  • Ruff: Exclusive linter/formatter. 160 char limit. Double quotes. Single-line imports.
  • Typing: Mandatory everywhere. from __future__ import annotations in every file.
  • Testing: pytest + unittest.mock. >90% coverage. Mirror source tree in tests.

PYTHONPATH

Devcontainer: set automatically — just run pytest tests/.

Standalone (replace $REPO_ROOT with the parent directory containing all submodules):

export PYTHONPATH="$REPO_ROOT/core/src:$REPO_ROOT/market/src:$REPO_ROOT/scenario/src"

Commands

ruff format .
ruff check . --fix
mypy src/
python -m pytest -v --cov=src/vaultdb_scenario
