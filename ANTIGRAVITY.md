# ANTIGRAVITY.md — vaultdb-web

## Repository Type
Pure static HTML/CSS/JS website. No build step, no framework.

## Source of Truth
- **Architecture & Standards**: `system-context.md` (always read this first)
- **Navigation**: `js/nav.js` is the SINGLE SOURCE OF TRUTH for all header, mobile sidebar, and footer content

## Key Rules
1. **Relative paths only** — never use `/` prefixed or absolute paths for local assets
2. **No build step** — no npm, no compilation, no transpilation
3. **No server dependencies** — site opens from `file:///` protocol
4. **CDN externals only** — Bootstrap, Font Awesome, AOS loaded from CDN with integrity hashes
5. **Navigation via js/nav.js** — DO NOT hardcode nav/footer HTML in pages; use placeholder divs

## Navigation Architecture
Every page uses three placeholder divs + a script tag:
```html
<div id="vdb-header"></div>
<div id="vdb-sidebar"></div>
... page content ...
<div id="vdb-footer"></div>
<script src="[depth]js/nav.js"></script>
```

To change menus, edit the data arrays in `js/nav.js`.

## Marketplace Generation
Marketplace pages are generated by `scripts/generate_marketplace.py`. The generator creates
HTML pages with nav.js placeholders — it does NOT extract layout from index.html.

Run: `python scripts/generate_marketplace.py`
