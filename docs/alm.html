VaultDB ALM

VaultDB ALM is a domain package for asset-liability management, gap analysis, and duration matching. It extends the VaultDB Core platform with alm-specific functionality.

Features

ALM Capabilities

  • Gap Analysis: Analyze maturity and repricing gaps across the balance sheet.
  • Duration Matching: Optimize asset-liability duration and convexity matching.
  • Balance Sheet Analytics: Comprehensive ALM reporting and analytics.

Installation

Prerequisites

  • Python 3.12 or higher
  • vaultdb.core >= 3.18.0

Install from PyPI

pip install vaultdb.alm

Install from Source

# Clone the repository
git clone https://github.com/vaultdbai/alm.git
cd alm

# Install in development mode
pip install -e .

# Install development dependencies
pip install -e ".[dev]"

Quick Start

import vaultdb_alm

Development

VaultDB ALM uses Ruff for linting and formatting (160 char limit) and Mypy for strict typing.

Commands

# Format and Lint
ruff format .
ruff check . --fix

# Type checking
mypy src/

# Testing
python -m pytest -v
