Implementation Plan: Unified Runner Interfaces

Objective

Create a unified interface across Celery, AWS Batch, and AWS Lambda runners while maintaining Celery scheduler compatibility for all runners.

Requirements

  1. All runners must have consistent interfaces
  2. All runners should support Celery scheduler
  3. Maintain backward compatibility with existing code
  4. Fix Python reserved keyword issue with lambda module name

Implementation Steps

2.4 Fix Lambda Import Issue

File: src/vaultdb/compute/core.py

Replace:

from ..lambda.core import LambdaRunner

With:

import importlib
lambda_module = importlib.import_module("..lambda.core", package=__package__)
LambdaRunner = lambda_module.LambdaRunner

Reason: lambda is a Python reserved keyword.
