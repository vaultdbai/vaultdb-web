VaultDB Core

VaultDB Core is the foundational layer of the KRONOS Re platform. It provides the data orchestration, task execution, authentication, approval, and API infrastructure that all domain submodules depend on.

Core Capabilities

Capability Module Description
Data Layer vaultdb.data DuckLake ORM, virtual forks, inherited reads, time-series models
Compute vaultdb.compute TED (Task Execution Dispatcher) — routes tasks to Celery, AWS Batch, or Lambda
Workflow vaultdb.workflow AI-proposed workflow lifecycle: submit, approve, execute with DAG ordering
Approval vaultdb.approval HMAC-SHA256 cryptographic approval records with policy enforcement
Auth vaultdb.auth OIDC, GitHub, AWS Cognito, Azure Entra ID authentication
Web API vaultdb.web FastAPI application with task endpoints and health checks
Caching vaultdb.cache Redis-based caching layer
Logging vaultdb.logger Structured logging with CloudWatch integration
Scheduler vaultdb.scheduler Business calendar-aware periodic task scheduling

Key Design Principles

  1. Strict Typing — MyPy disallow_untyped_defs = True. Every function, parameter, and return type is annotated.
  2. Vectorization First — Arrow/DuckDB compute kernels over Python loops.
  3. Configuration Authority — All config flows through vaultdb.config. No os.getenv in business logic.
  4. Sandbox Isolation — User-specific schemas (sandbox_<role>) for non-production writes.
  5. Human-in-the-Loop — Every material action requires a cryptographically verified human approval.
