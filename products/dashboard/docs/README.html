KRONOS Re Dashboard Documentation

This directory contains detailed documentation for the KRONOS Re analytical dashboard.

Overview

The dashboard is built using Plotly Dash and serves as the primary analytical front-end for the VaultDB platform. It provides visualizations for: - Overview: High-level portfolio analytics. - Liability: Cashflow projections and reserve tracking. - ALM: Duration gap and NII simulation. - Trading: Portfolio construction and order execution. - Risk: Greeks, VaR, and stress test results. - Reports: Regulatory and financial filing generation. - AI Chatbot: Actuarial AI assistant.

See system-context.md in the submodule root for technical specifications.
