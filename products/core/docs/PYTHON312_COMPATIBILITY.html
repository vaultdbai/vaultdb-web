Python 3.12 Compatibility Fixes

Issue

Python 3.12 removed the distutils module, which was causing import errors:

ModuleNotFoundError: No module named 'distutils'

Solution

Updated setup.py to use setuptools._distutils instead of distutils directly, which provides the same functionality for Python 3.12+.

Changes Made

1. Updated setup.py imports

Before:

from distutils.command.build_ext import build_ext
from distutils.errors import CCompilerError

After:

# Python 3.12+ compatibility: distutils was removed, use setuptools
try:
    from setuptools._distutils.command.build_ext import build_ext
    from setuptools._distutils.errors import CCompilerError
    # ... etc
except ImportError:
    # Fallback for older Python versions
    from distutils.command.build_ext import build_ext
    # ... etc

2. Updated requirements.txt

Added minimum setuptools version that includes distutils replacement:

setuptools>=68.0.0  # Python 3.12+ compatible, includes distutils replacement

3. Updated Cython compatibility

Fixed Cython imports to work with both old and new versions:

try:
    from Cython.Distutils import build_ext as cython_build_ext
except ImportError:
    # Cython 3.0+ or Python 3.12+: use setuptools build_ext directly
    cython_build_ext = build_ext

4. Improved error handling

Made _have_sqlite_extension_support() more robust to handle missing compilers gracefully.

Verification

The setup.py now imports successfully on Python 3.12:

python -c "from setuptools._distutils.command.build_ext import build_ext; print('OK')"
# ✓ All distutils imports successful from setuptools (Python 3.12 compatible)

Compatibility

  • ✅ Python 3.11 (uses distutils if available, falls back to setuptools)
  • ✅ Python 3.12+ (uses setuptools._distutils)
  • ✅ Backward compatible with older Python versions

Notes

  • The gcc compiler error is expected if you don't have a C compiler installed
  • This only affects building C extensions (SQLite extensions)
  • The package will still install and work without C extensions
  • To build C extensions, install build tools: dnf install gcc sqlite-devel (or equivalent)
