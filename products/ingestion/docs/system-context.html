System Context: VaultDB Ingestion

Package Mission vaultdb.ingestion provides the data normalization and import pipeline for the VaultDB platform. It handles the ingestion of policy census data from ceding carriers (life insurers, annuity providers). It normalizes disparate file formats (CSV, Excel) into standard PolicyRecord models, performs sanity checks (generated by AI or rules), and allows for actuarial review and resolution of flags before promoting data to the production liability models.

Dependencies: vaultdb.core (data layer, models).

Tech Stack

  • Language: Python 3.12+ (Strict typing: disallow_untyped_defs = True)
  • Data Layer: DuckLake/DuckDB via vaultdb.data.Model and vaultdb.data.TimeSeriesModel
  • Core Dependency: vaultdb.core>=3.18.0
  • Data Parsing: pandas, openpyxl (for Excel)
  • Tooling: Ruff, MyPy, Pytest

Project Map

  • /src/vaultdb_ingestion/: Base package.
    • models.py: IngestionJob, PolicyRecord, IngestionFlag, FieldMappingTemplate — Model definitions for tracking jobs and records.
    • parser.py: Implementation of census file parsing and normalization logic.
    • tasks.py: Celery/TED tasks for running ingestion jobs and auto-flagging records.
  • /tests/: Unit and integration for parsers and data models.

Key Design Decisions

Ingestion Pipeline

  1. Job Creation: Create an IngestionJob.
  2. Parsing: Parse raw files using FieldMappingTemplate.
  3. Normalization: Map raw fields to normalized PolicyRecord fields.
  4. Flagging: Run sanity checks to create IngestionFlag objects.
  5. Review: Analysts resolve flags and promote records to the liability module.

State Management

Uses TimeSeriesModel for IngestionJob to track status and metadata of every import attempt.

Behavioral Guardrails (No-Go Zones)

  • Strict Configuration: NEVER use os.getenv or os.environ directly. Use vaultdb.config.
  • No Prints: NEVER use print(). Use vaultdb.logger.
  • No Peewee: NEVER import from peewee. Use vaultdb.data column types.
  • Data Privacy: Be careful when logging PII (Personally Identifiable Information) from census files. Log record IDs but avoid logging raw names or SSNs.

Coding Standards

  • Ruff: Exclusive tool for linting and formatting. 160 char limit.
  • Typing: Mandatory type hints everywhere.
  • Testing: pytest + unittest.mock.
