End-to-End Architecture

Deployment Topology

KRONOS Re runs as a set of supervised services orchestrated by systemd/supervisord:

  • KRONOS Dashboard (port 8050) — Dash application serving the primary UI
  • KRONOS API (port 8000) — FastAPI router for task execution and data access
  • ChatHub (port 8060) — Per-user AI chatbot process manager
  • User Servers (ports 9100-9999) — Isolated Claude SDK conversation loops

Module Dependency Graph

All modules depend on Core for data access, authentication, and compute orchestration. The dependency flow is:

Ingestion → Market + Assumptions → Asset + Liability → Scenario → Valuation + ALM → Trading → Risk → Reporting → Dashboard

Compute Engines

Computationally intensive operations (cash flow projection, Monte Carlo simulation, portfolio pricing) use PyTorch tensors for GPU-accelerated vectorization. The TorchMixin base class provides device management, discount factor generation, survival chain computation, and automatic differentiation for sensitivity analysis.

Interest Rate Models

The platform implements two stochastic interest rate models for liability valuation:

  • Hull-White 1F — Mean-reverting short rate model with exact OU discretization
  • Heath-Jarrow-Morton (HJM) — Multi-factor forward rate model with no-arbitrage drift constraint

Both produce PyTorch discount factor tensors of shape (n_scenarios, n_periods) for vectorized present-value computation across the liability portfolio.
